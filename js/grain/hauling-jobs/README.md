# Hauling Jobs

- root of this folder — active hauling-job list/progress/assignment behavior
- `forms/` — add/edit hauling-job forms and picker behavior
- `legacy/` — older picker revisions encountered during migration

Legacy files are not assumed safe to delete merely because a newer version exists. Their consumers must first be identified. Any version with no active consumer can be removed as part of the cleanup only after repository-wide reference verification.
